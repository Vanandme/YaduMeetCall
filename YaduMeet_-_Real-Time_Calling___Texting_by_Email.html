Deploy YaduMeet Free on GitHub Pages

This entire application is self-contained in a single HTML file. Follow these steps to host your own live instance:

  1. Step 1: Create GitHub Repository Go to github.com/new and create a public repository named yadumeet.
  2. Step 2: Add index.html File Create a file named index.html in your repository and paste the complete code of this document into it.
  3. Step 3: Enable Pages Hosting Navigate to Settings > Pages in your GitHub repository. Under Build and deployment / Source, choose Deploy from a branch, select main branch and click Save.
  4. Step 4: Connect & Call Open your live URL (https://yourusername.github.io/yadumeet) on two separate devices or browser tabs, sign up with different emails, and start live calling!
